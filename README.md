# SaaS Dashboard

یک داشبورد مدرن و واکنش‌گرا برای پروژه‌های SaaS که با React، TypeScript، Vite، Tailwind CSS، Material UI و Recharts ساخته شده است.

## دمو

نسخه آنلاین پروژه:

**[مشاهده دمو](https://saas-dashboard.freedev.app/)**

## قابلیت‌ها

* طراحی مدرن و واکنش‌گرا
* داشبورد مدیریتی با نمودارهای تعاملی
* پشتیبانی از حالت روشن و تاریک
* سایدبار واکنش‌گرا
* کامپوننت‌های قابل استفاده مجدد
* نمایش و تحلیل داده‌ها با Recharts
* نمایش کد با Syntax Highlighting
* استفاده همزمان از Tailwind CSS و Material UI
* پشتیبانی از TypeScript

## تکنولوژی‌های استفاده‌شده

* **React** — ساخت رابط کاربری
* **TypeScript** — Type Safety و نگهداری بهتر کد
* **Vite** — ابزار توسعه و Build
* **Tailwind CSS** — استایل‌دهی و طراحی رابط کاربری
* **Material UI** — کامپوننت‌ها و آیکون‌های رابط کاربری
* **Recharts** — ساخت نمودار و نمایش داده‌ها
* **React Syntax Highlighter** — نمایش کد با Syntax Highlighting
* **ESLint** — بررسی کیفیت و خطاهای کد
* **Prettier** — فرمت کردن کد

## نصب و اجرا

### پیش‌نیازها

برای اجرای پروژه به Node.js و npm نیاز دارید.

### دریافت پروژه

```bash
git clone https://github.com/ImRez69/SaaS-Dashboard.git
cd SaaS-Dashboard
```

### نصب وابستگی‌ها

```bash
npm install
```

### اجرای پروژه در حالت توسعه

```bash
npm run dev
```

بعد از اجرای دستور، Vite آدرس اجرای پروژه را در ترمینال نمایش می‌دهد.

## دستورات پروژه

| دستور             | توضیح                              |
| ----------------- | ---------------------------------- |
| `npm run dev`     | اجرای پروژه در حالت توسعه          |
| `npm run build`   | ساخت نسخه Production               |
| `npm run preview` | اجرای نسخه Production به صورت محلی |
| `npm run lint`    | بررسی کد با ESLint                 |

## ساختار پروژه

```text
SaaS-Dashboard/
├── public/              # فایل‌های استاتیک
├── src/                 # کد اصلی پروژه
├── index.html           # فایل اصلی HTML
├── package.json         # وابستگی‌ها و تنظیمات پروژه
├── tsconfig.json        # تنظیمات TypeScript
├── vite.config.ts       # تنظیمات Vite
├── .prettierrc          # تنظیمات Prettier
└── .oxlintrc.json       # تنظیمات Oxlint
```

## TypeScript

این پروژه در حال مهاجرت از JavaScript به TypeScript است.

نسخه TypeScript پروژه در branch جداگانه `typescript` توسعه داده می‌شود تا تغییرات مربوط به TypeScript بدون ایجاد اختلال در نسخه اصلی پروژه انجام شوند.

هدف از این مهاجرت، افزایش Type Safety، کاهش خطاهای زمان اجرا و بهبود نگهداری و توسعه پروژه است.
